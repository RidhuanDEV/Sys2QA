# Acme portal

Customer portal for placing and approving orders. This README was written for the first release and has not been
updated since.

## Accounts

Customers register with an email address, a password of at least 8 characters and their 13-digit NIB (business
identification number). A forgotten password can be reset by email.

## Orders

Customers place orders for amounts between 1 and 10000. An administrator approves or rejects each submitted order.
